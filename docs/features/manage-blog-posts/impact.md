**Risks**

- R-1 (the draft flag drifts): if a later change stops writing `draft: true` for Draft, a draft becomes public. Likelihood low, cost high (intent §2.5). Carried: D-07, TS-01, TS-02, Step 1 and Step 2 are `Risk: high`, E2E-03, E2E-05, E2E-06, E2E-12.
- R-2 (a stale list lets a save overwrite a post): a plain write would replace a post another tab just created. Likelihood medium without a guard, cost medium. Carried: D-11 (transaction), E2E-09, E2E-10, E2E-22 (the store contains `runTransaction` and no `setDoc(`).
- R-3 (the whole-collection read is refused for a non-owner): for the "unfilled" account the editor cannot list posts (`firestore.rules:43` needs `isOwner()` for a list query), so it shows `The entries could not be loaded.` and nothing is writable. Likelihood certain for that state, cost low (saving is off anyway). Carried: D-20, E2E-19.
- R-4 (`blogPosts` documents seeded by `admin-owner-only-access`): `e2e/admin-owner-only-access.spec.ts` seeds `blogPosts/e2e-05`, `e2e-07`, `e2e-08`, `e2e-09`, `e2e-10`, `e2e-10-nodraft`, `e2e-11-draft`, `e2e-11-pub` and may leave them in the shared emulator. Carried: `ownerSession` clears `blogPosts` and `images` first, and `blogPostFromData` reads partial documents as empty text with status Draft.
- R-5 (a hand-written post whose document id is not a valid slug cannot be saved from the edit form, because the slug cannot be changed): only hand-written data can cause it; the panel never creates one. Likelihood very low, cost low. Carried: D-25 (delete it and add it again).
- R-6 (a very long body exceeds the document size limit): the save fails and shows the shared failure message; nothing is stored. Likelihood very low, cost low. Carried: D-13.
