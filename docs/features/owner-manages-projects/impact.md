**Risks**

- **R-1 The real SQL and library are never run by automation** (decomposition Open finding 1). Proven on PostgreSQL itself by SF-2; not proven through Supabase's pooler. Likelihood low, cost one SIT round. Carried as Decision D-14, E2E-32 (manual) and Step 1's Stop-if.
- **R-2 Tab divergence (story Assumption 11).** Two tabs adding or moving at once can leave two projects at the same position; they then list in insertion order. Likelihood low (one owner), cost a manual re-move. Accepted, Decision D-17.
- **R-3 An earlier spec is edited by a later feature.** The sign-in spec's loop gains a third label this slice and will gain Certifications, Tech stack and Blog posts in the next ones; the profile and uploads specs already use "Blog posts" and are touched by the blog slice only. Likelihood certain, cost one line each. Recorded in D-10 for the later writers.
- **R-4 A paused Supabase project** shows "The entries could not be loaded." (accepted in intent §4). No keep-awake job.
- **R-5 The schema step is shared** (SF-4): a pooler refusal of the new table statement would hide the profile, images, experience and projects screens at once on SIT. Likelihood low (the same text works for `experience`), cost one SIT round.

**Cleared**

- No new dependency, setting name or gate edit: `git grep -ohE "process\.env\.[A-Za-z_]+" -- src` lists only `ADMIN_EMAIL`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `AUTH_SECRET`, `NODE_ENV`, `SUPABASE_DB_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `SUPABASE_URL` (the experience impact's list; this slice adds no `process.env` use); `scripts/check-task.sh` already allows new files under `src/app/api/admin/`.

- `database.ts` and `standin.ts` need no edit: every list function takes the table name and the stand-in key is that name (`database.ts:222-310`, `standin.ts:71-80`), so the profile, images, experience and projects share one stand-in file without a collision.

- `checkProject` already trims, drops blank paragraphs and tech names, and checks both links (`projects.ts:25-47`); the server reuses it, so the browser and the server cannot disagree.
