**Risks**

- **R-1 The real SQL and library are never run by automation** (decomposition Open finding 1). Proven on PostgreSQL itself by SF-2, including the nested `jsonb`; not proven through Supabase's pooler. Likelihood low, cost one SIT round. Carried as Decision D-16, E2E-36 (manual) and Step 1's Stop-if.
- **R-2 Tab divergence (story Assumption 18).** Two tabs adding or moving at once can leave two categories at the same position; they then list in insertion order. A category is saved whole, so a stale tab that saves a category overwrites the items another tab changed (last save wins, no warning). Likelihood low (one owner), cost a manual re-edit. Accepted, Decision D-18.
- **R-3 Earlier specs are edited by later slices.** The sign-in spec's loop gains a sixth label this slice; the projects and certifications specs pin the table set and will need the same one-line edit when the blog table is added, and so will this feature's own spec. Likelihood certain, cost one line each. Recorded in D-12 for the blog posts slice's writer.
- **R-4 A paused Supabase project** shows "The entries could not be loaded." (accepted in intent §4). No keep-awake job.
- **R-5 The schema step is shared** (SF-5): a pooler refusal of the new table statement would hide the profile, images, experience, projects, certifications and tech stack screens at once on SIT. Likelihood low (the same text works for the other tables), cost one SIT round.
- **R-6 A typed address of the uploaded form is accepted whether or not the file exists** (D-5). The owner could store `https://other.example/storage/v1/object/public/images/x` and the icon would load from there or fail to load; nothing else is exposed. Likelihood very low, cost a broken icon. Accepted, Decision D-5, probed by E2E-02.
- **R-7 An item whose uploaded image is deleted later** keeps its saved address and shows as a broken image on a later public page (story Assumption 3). The screen shows the address as text in the item's icon path and in its row line, and saving the category with it unchanged is accepted. Accepted, Decision D-25, row E2E-31.
