- **R-1** (confirmed, high likelihood, low cost): this feature changes `experienceTimeLine.tsx`, which `e2e/retire-firebase.spec.ts:60` (E2E-47) and `e2e/hosting-and-backend-migration-acceptance.spec.ts:1300` (E2E-ACC-16) require to equal the pre-migration commit. Both fail after Step 1 until Step 2 removes the file from their lists. Carried: TS-06, Step 2.
- **R-2** (unproven, low likelihood, medium cost): if the page's experience read fails during a regeneration while Publish's profile read succeeded, the framework's behaviour (keep the old copy, or fail the visit) is unproven here. The same open item exists for the profile (earlier feature's OQ-1). Both reads go to one database through one client, so a split failure is not expected. Carried: Open Question OQ-1 and D-04; `site-survives-database-outage` proves the outage case for every section.

Carried: TS-05, TS-06, TS-07.
