**Risks**

- R-1 (confirmed, likelihood medium, cost medium): other spec files run in parallel against the one stand-in database, and several reset it or publish. A feed test can therefore see another file's posts, or lose its own. Carried to Decision D-09: unique slugs per test, assertions only on the test's own slugs (the empty-feed test polls until the feed is empty), 60-second polls, and a `blankPublished`-style helper in `try/finally` that leaves the database empty and published.
- R-2 (confirmed, likelihood high, cost low): the layout-type renewal of a feed path is easy to drop in a refactor because the tag alone appears to work on the real host. Carried to TS-04, Decision D-02 and E2E-14 (the source has both calls) and E2E-01 (first Publish after an empty build renews the feeds).
- R-3 (confirmed, cost low): a failed database read while a feed renews throws, so Vercel keeps the previous copy; keeping them across an outage is the outage slice's. Carried to Decision D-06.

**Cleared**

- `src/lib/server/publicPosts.ts` is imported only by server files; the two feed files are server routes, so no browser bundle gains it.
- The feeds stay `force-static` kept copies: the scratch build lists both as `○ (Static)` and `initialRevalidateSeconds: false`; no `revalidate` timer is added.
- `src/app/api/admin/publish/route.ts` needs no edit: it already calls `refreshPublishedPosts()` after the owner check and the reachability probe, so a refused or failed Publish renews nothing (earlier slice's tests).
- The robots file, the blog pages and `next.config.ts` are untouched; `trailingSlash` agreement is unaffected (`absoluteUrl` gives `/blog/<slug>/`).

**Before merge**

- E2E-01 (the first Publish after a build that held no posts renews both feeds) and E2E-04 (a saved post stays out until Publish) catch the second and third safety facts above.
- E2E-14 (source has the tag expiry and both layout-type renewals, and the feed files read only the snapshot) and E2E-15 (both routes stay prerendered with no timer).
- E2E-18, the owner's one real publish on SIT.
