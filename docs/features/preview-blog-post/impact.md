**Risks**

- The converter's packages might not bundle for the browser (likelihood low, cost one Step blocked). Check: `npm run build` in Step 2. Carried: Step 2 **Stop-if**; D-04 says the spec writer then decides.
- The wide-table scroller depends on `.prose table` not setting `display: block` inside `overflow: hidden` on an ancestor (`globals.css:518-521` sets `overflow: hidden` on the table itself, which has no effect on a table-display element). Likelihood low. Check: E2E-06 asserts the scroller's `scrollWidth` exceeds its `clientWidth` and that the last cell is reachable. Carried: TS-02, D-11.
- `BlogArticle` markup drift would change the public page (likelihood low, cost high: intent §5). Check: E2E-09. Carried: TS-01, TS-05.
